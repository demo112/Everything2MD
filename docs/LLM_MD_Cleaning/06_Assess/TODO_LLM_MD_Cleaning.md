## 操作指引

1.  打开 Everything2MD GUI。
2.  切换到 "解析增强" 标签页。
3.  勾选 "启用结构化清洗功能"。
4.  填入 LLM 的 API Base URL, API Key, Model。
5.  进行文档转换，查看日志输出中的 "Structure Cleaning" 相关信息。
