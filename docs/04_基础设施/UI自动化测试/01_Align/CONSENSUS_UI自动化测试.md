# CONSENSUS_UI自动化测试

## 1. 需求共识
**目标**: 为 Everything2MD 引入 UI 自动化测试框架，覆盖真实用户交互场景。

**核心决策**:
- **框架选型**: 使用 `pywinauto` (Backend: 'uia')。
- **理由**: 项目使用 Tkinter 开发，且运行在 Windows 环境。`pywinauto` 提供了最接近真实用户的交互模拟能力（鼠标点击、键盘输入），优于 `pytest-qt`（不兼容 Tkinter）和图像识别方案。
- **测试范围**:
  - 应用启动与关闭。
  - 核心流程：设置输入/输出路径 -> 点击转换 -> 验证结果。
  - 界面元素存在性验证（按钮、标签）。

## 2. 验收标准
1.  **依赖安装**: `requirements.txt` 中包含 `pywinauto`。
2.  **测试通过**: 至少有一个端到端 (E2E) 测试用例能够成功运行（启动 App -> 执行操作 -> 关闭 App）。
3.  **文档完整**: 包含测试运行指南。
4.  **无侵入性**: 测试不应修改现有 GUI 代码（除非为了增加 accessibility ID）。

## 3. 技术约束
- **运行环境**: 仅支持 Windows 环境运行 UI 测试（CI/CD 若在 Linux 上需跳过此部分测试）。
- **执行方式**: 通过 `pytest` 运行，使用 `subprocess` 启动待测应用。
