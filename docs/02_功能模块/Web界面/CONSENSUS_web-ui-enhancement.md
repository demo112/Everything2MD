# Web界面增强 - 共识文档 (Consensus)

## 1. 目标 (Objectives)
构建一个响应迅速、实时反馈、配置灵活的 Web 界面。

## 2. 交付物 (Deliverables)
1. **增强版后端 (`web/backend/main.py`)**:
   - 支持 WebSocket 路由 `/ws/logs`。
   - 转换任务改为后台线程/进程执行。
   - 支持实时捕获子进程输出并推送到 WebSocket。
   - 启动端口可配置。
2. **增强版前端 (`web/frontend/`)**:
   - 集成 WebSocket 客户端，实时更新终端窗口。
   - 增加“停止任务”按钮（可选，视复杂度而定）。
   - 优化文件选择器的盘符切换体验。

## 3. 技术规范 (Specifications)
- **API**:
  - `POST /api/convert`: 启动异步任务，返回 task_id。
  - `WS /ws/logs/{task_id}`: 订阅特定任务的日志。
- **并发控制**:
  - 简单起见，全局同一时间只允许一个转换任务运行（避免资源竞争和日志混乱），或者通过 task_id 区分。考虑到单用户场景，全局锁即可。
- **端口配置**:
  - 优先读取环境变量 `WEB_PORT`，默认 9527。

## 4. 验收标准 (Acceptance Criteria)
- [ ] 点击“开始转换”后，UI 不卡顿。
- [ ] 终端窗口实时逐行显示转换日志。
- [ ] 可以顺利从 C 盘切换到 D 盘（如果存在）选择文件。
- [ ] 后端启动端口可修改。
