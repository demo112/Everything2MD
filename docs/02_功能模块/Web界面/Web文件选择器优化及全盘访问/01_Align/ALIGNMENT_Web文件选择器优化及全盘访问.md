# Alignment: Web文件选择器优化及全盘访问

## 原始需求
1. **布局与样式问题**：Web文件选择器布局错乱，字体颜色在暗黑模式下看不清（可能是白色背景导致）。
2. **全盘访问需求**：路径选择需要能够选择PC所有的路径（C, D, E, F盘），而不仅仅是项目目录。

## 现状分析
- **前端架构**：HTML/CSS/JS 原生实现，无框架。目前 `index.html` 包含大量内联样式，难以维护且与 `style.css` 中的暗黑模式冲突。
- **后端架构**：FastAPI 提供 API。目前文件列表 API 仅限于访问特定目录。
- **Docker环境**：项目运行在 Docker 容器中，容器默认无法直接访问宿主机的所有盘符，需要配置 Volume 挂载。

## 疑问与澄清
- **Q**: 是否需要保留原有的项目目录访问？
  - **A**: 是，作为默认或快捷访问。
- **Q**: 宿主机有哪些盘符需要挂载？
  - **A**: C, D, E, F。
- **Q**: 如何在界面上展示这些盘符？
  - **A**: 在根目录（ROOT）下显示盘符列表，类似于 "我的电脑"。

## 结论
需要同时修改前端（样式重构、逻辑增强）、后端（API扩展）和 Docker 配置（挂载盘符）。
