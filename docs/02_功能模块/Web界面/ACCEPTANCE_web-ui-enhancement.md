# Web界面增强 - 验收报告 (Acceptance)

## 1. 验收项
- [x] **实时日志**: 后端实现了 WebSocket 广播机制，前端成功连接并接收日志。
- [x] **异步任务**: 转换任务已改为后台 `asyncio.subprocess` 执行，不再阻塞 HTTP 请求。
- [x] **端口配置**: 支持 `--port` 参数和 `WEB_PORT` 环境变量。
- [x] **跨盘符导航**: 后端逻辑支持根路径 `/` 列出所有盘符，前端支持导航至根路径。

- **启动**: `py -3 web/backend/main.py --port 9528` 正常启动（依赖安装后）。
- **连接**: 前端自动识别当前端口并建立 WebSocket 连接。
- **转换**: 提交任务后立即返回 "started"，随后通过 WebSocket 接收日志流。
