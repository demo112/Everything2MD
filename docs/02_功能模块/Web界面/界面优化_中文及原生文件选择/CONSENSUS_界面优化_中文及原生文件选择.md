# CONSENSUS: 界面优化_中文及原生文件选择

## 1. 需求定义
*   **核心目标**：提升本地Web使用的原生体验和易用性。
*   **交付物**：
    *   更新后的 `web/backend/main.py`：支持服务端弹出系统文件选择框。
    *   更新后的 `web/frontend/index.html`：中文界面，移除旧文件选择器。
    *   更新后的 `web/frontend/script.js`：对接新API，中文交互提示。

## 2. 边界与约束
*   **运行环境**：必须在有桌面环境的机器上运行（Windows/Mac/Linux GUI），否则系统弹窗会失败或报错。当前确认为 Windows 本地环境。
*   **浏览器限制**：浏览器端仅发起请求，不直接处理文件流。
*   **并发**：弹窗会阻塞后端线程，需注意异步处理或接受短时阻塞。由于是单用户本地工具，阻塞可接受。

## 3. 验收标准
*   点击“浏览”按钮能弹出 Windows 原生文件/文件夹选择框。
*   选择后，路径正确回填到输入框。
*   界面无英文字符（除专有名词如 Markdown, PDF 等）。
*   转换流程正常工作。
