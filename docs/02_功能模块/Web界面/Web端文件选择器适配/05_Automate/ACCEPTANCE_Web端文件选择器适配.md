## 故障排查记录
- **现象**: 部署新代码后，点击选择文件仍报错 "no display name"，提示仍在调用系统组件。
- **原因**: 浏览器缓存了旧版 `script.js`，导致前端仍在请求旧的 `/api/system/select-path` 接口。
- **解决**: 
  1. 修改 `index.html` 引入脚本处，增加版本号 `script.js?v=20251201-01` 以强制刷新缓存。
  2. 指引用户强制刷新浏览器 (Ctrl+F5)。
