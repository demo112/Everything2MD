# ALIGNMENT_修复文件选择组件

## 1. 需求分析
用户反馈“文件选择组件有问题。各种路径都选不到”。
结合上下文，用户可能正在使用运行在 Docker 中的 Web 界面。
如果是在 Docker 中运行 Web 应用，浏览器端选择的文件路径是用户宿主机的路径，而后端在 Docker 容器内，两者文件系统隔离。
或者，组件本身实现有误，导致无法点击或选择。

## 2. 现状排查
需要检查前端代码实现文件选择的方式：
1. 是使用 `<input type="file">` 上传文件？
2. 还是输入服务器端路径？
3. 还是通过 API 获取服务器端目录树进行选择？

## 3. 假设
- **场景**: Web UI (Docker环境)
- **问题**: 路径选择无效，可能是因为浏览器安全限制（无法获取完整本地路径）或 Docker 环境路径隔离问题。

## 4. 待确认问题
- 前端代码位置：`web/frontend`
- 后端处理逻辑：`web/backend`
