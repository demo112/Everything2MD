# 配置系统重构

## 任务背景
用户反馈配置持久化问题频发（如文档结构化配置未保存），希望从根本上解决此类问题，避免未来再次发生。

## 任务目标
1. 重构 `ConfigManager`，消除硬编码的键值映射，统一配置管理。
2. 重构 GUI 配置绑定机制，实现自动化绑定，减少手动同步代码。
3. 确保所有配置项（包括新增的结构化清洗配置）都能正确持久化。
4. 保持向下兼容性。
