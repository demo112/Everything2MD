## 1. 需求背景
用户反馈：
1. 上传文件时，即使全选了文件，提示“完成0，成功0”。
2. 项目测试覆盖率不足。

## 2. 问题分析
### 2.1 上传失败
- **原因**: `src/gui/main.py` 中 `upload_selected_files` 方法获取 Treeview 数据时，列索引错误。新增的复选框列占用了索引 0，导致原有的文件名列（原索引 0）变为索引 1。代码仍尝试从索引 0 获取文件名，导致匹配失败。
- **影响**: 无法上传任何文件。

### 2.2 测试覆盖率
- **现状**: 核心转换逻辑 (`OfficeConverter`) 和 GUI 逻辑测试覆盖率较低。
- **目标**: 
    - 修复上传功能的 Bug。
    - 增加 GUI 上传逻辑的单元测试。
    - 增加 `OfficeConverter` 重试逻辑的单元测试。
    - 确保所有测试通过。

## 3. 解决方案
1. **修复 Bug**: 修改 `src/gui/main.py` 中的列索引获取逻辑。
2. **新增测试**:
    - `test/unit/gui/test_rag_upload.py`: 专门测试 GUI 上传逻辑（Mock Treeview 和 Client）。
    - `test/unit/core/converters/test_office_retry.py`: 测试文件复制和转换的重试机制。
3. **回归测试**: 运行所有单元测试，确保无回归。
